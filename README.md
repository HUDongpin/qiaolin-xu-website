# Qiaolin XU (Shirleen) Educator Portfolio

A production, multi-page professional portfolio for an early childhood educator preparing for a future U.S. Master of Arts in Teaching and teaching licensure pathway.

## Routes

- `/` - professional introduction
- `/teaching` - documented K3 classroom practice
- `/experience` - teaching and academic-operations roles
- `/education` - completed education and planned U.S. pathway
- `/qualifications` - language proficiency and reported assessment scores
- `/service` - volunteer participation
- `/contact` - professional contact and public CV download

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

The site is designed for light and dark system themes, keyboard navigation, reduced-motion preferences, and responsive viewports from 320 pixels upward.
